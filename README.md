# IA-Use — Multi-AI Desktop Workspace & Orchestrator

Un'applicazione desktop macOS (Electron) che incapsula le Web UI ufficiali dei tuoi abbonamenti AI (ChatGPT, Claude, Gemini, Perplexity, DeepSeek, Grok) in un unico ambiente di lavoro con:
- **Multi-Prompt in Parallelo** (Split-Screen 1, 2, 3 o 4 colonne / griglia)
- **Relay & Passaggio di Contesto 1-Click** (prendi l'ultima risposta o il testo selezionato da un'AI e invialo a un'altra con template di verifica, refactoring o sintesi)
- **Sessioni Persistenti & Google OAuth Ready** (nessun bisogno di API key a consumo: usa i tuoi abbonamenti Pro/Plus/Advanced)
